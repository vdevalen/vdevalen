## ☁️ about me

I started in tech **without a computer, without courses, and with no idea where to begin**.
Today I build cloud-native systems, lead one of Colombia's most active dev communities, and create content that makes technology feel possible for everyone.

One day in La Guajira, a girl asked me: *"can I also be an engineer like you?"*
That moment defined my purpose. 💜

- 🏗️ **Building** cloud-native solutions with Go, TypeScript and Google Cloud
- 🎤 **Leading** GDG Medellín — free monthly events, talks and mentorships
- 📱 **Creating** technical content for **13K+ devs** on Instagram
- 🌿 **Volunteering** — bringing tech to communities with no access
- ☕ **Coding** from my setup or the closest coffee shop
